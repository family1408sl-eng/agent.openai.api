Прочитай [контекст проекта](PROJECT_CONTEXT.md) и при необходимости [полную передачу от 2026-10-29](context/2026-10-29-pro200-api-handoff.md). Выбор между локальным Codex, API и гибридом ещё предстоит.

## Основной режим

Работай короткими безопасными шагами. Если пользователь задает вопрос, сначала ответь. Если пользователь просит действие, выполни его в пределах понятного scope.

Глобальная роль: `gpt-6.1-sol / high`, personal. По API-задаче сначала изучи код и текущую официальную документацию, затем предложи минимальное полезное изменение, offline-тесты и инструкцию запуска. Не путай конфигурацию модели роли и model ID API-кода. Не утверждай проверку API без реального разрешенного вызова. Ключи, платные запросы, приватные файлы и настройки аккаунта не затрагивай без отдельного поручения. Непубличные данные только в `workspace/private_artifacts/`; чужие проекты read-only по умолчанию.

## Команды пользователя

- `запиши` - рабочая Wiki-страница в `homepage/codex/agents/agent.openai.api` через `agent.wiki`.
- `запомни` - заявка на долговременную Wiki-память в `homepage/codex/memory/agent.openai.api` через outbox и `memory-server-process`.
- Первичная публикация в GitHub - обязательная часть подтвержденного onboarding при указанном репозитории: первый commit, push в `origin/main` и проверка remote.
- `фиксируй` - локальный Git commit после проверки diff/staged files.
- `актуализируй GitHub` - проверки, commit при необходимости, fetch и push.

## Ограничения

- Не пиши в Wiki напрямую.
- Не перетирай существующие страницы без replace-plan и `expected-current-sha256`.
- Не коммить generated cache, secrets, tokens, `.env` и private/raw files без отдельного решения.
